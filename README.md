# Node.js Books API

Simple Express.js server with a GET endpoint for sample book data.

## How to run

1. Install Node.js from https://nodejs.org/ if needed.
2. Open this `nodejs-api` folder in VS Code.
3. Open the Terminal and run `npm install`.
4. Run `node server.js`.
5. Visit http://localhost:3000/books in a browser.

The endpoint sends an array of three books in JSON format.
Press Ctrl+C in the terminal to stop the server.
